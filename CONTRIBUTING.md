# Contributing to Spellmerge

Thanks for wanting to help! Spellmerge is built by Claude, an AI, and shaped by the people who play it. You don't need to write code or open pull requests: Claude writes the code and the assets itself. What it needs from you is what it can't see by itself: bugs you hit, ideas you have, and how the game feels.

## Ways to help

| You want to | Where |
| --- | --- |
| Report a bug | The **[Report a bug](https://github.com/peterdk31/spellmerge/issues/new/choose)** form |
| Suggest a spell, an enemy, a relic, anything | The **Spell idea** form, or [Discussions → Ideas](https://github.com/peterdk31/spellmerge/discussions/categories/ideas) |
| Show off a combo | [Discussions → Spell combos](https://github.com/peterdk31/spellmerge/discussions/categories/spell-combos) |
| Give feedback on the look or the feel | [Discussions](https://github.com/peterdk31/spellmerge/discussions) |
| Raise a copyright concern | The **Report a copyright concern** form |

The more exact a bug report, the faster it gets fixed: the build version (on the main menu), how many players, and the steps.

## What happens next

Once a day (03:00 UTC), Claude reads every new issue and discussion and answers each one:

- **Scheduled:** it goes into Claude's work queue, by priority (crashes and blockers first). The pull request that does it closes your issue, so you are notified.
- **Backlog:** a good idea for later. The weekly planning schedules it when it fits a milestone.
- **Needs info:** Claude asks for what's missing. Reply in the same place, and it reads it again the next day.
- **Answered, duplicate or declined:** with a reason, in plain words.

Ideas that come in as a discussion or a pull request get their own issue, linked in the reply, so you can follow them. Pull requests are read as suggestions and closed: the bot writes its own version, so nobody has to sign anything or worry about licenses.

You can see the work queue ([`scheduled`](https://github.com/peterdk31/spellmerge/issues?q=is%3Aopen+label%3Ascheduled)) and the [`backlog`](https://github.com/peterdk31/spellmerge/issues?q=is%3Aopen+label%3Abacklog) at any time. Every bot action is listed in the day's [Daily log](https://github.com/peterdk31/spellmerge/issues?q=label%3Adaily-log).

## Credit

Players whose bug reports or ideas made it into the game are on the in-game credits screen, and the most helpful may name a spell. The web version stays free forever; the Steam version funds development.

## Code of conduct

Be kind and constructive. Critique work, not people. Claude and the owner may close or lock anything that isn't.

## Security

Report security problems privately through [Security advisories](https://github.com/peterdk31/spellmerge/security/advisories/new), not in a public issue.
