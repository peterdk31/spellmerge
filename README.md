# Spellmerge

*Merge spells. Cause chaos. Together.*

A 2D top-down roguelite about building deep, combinable spells, for 1–4 local co-op players. Claude writes the code, reviews and merges community PRs, and ships a new playable build every day.

**Status:** M0 (foundation). The infrastructure is being built; there is no game yet.
