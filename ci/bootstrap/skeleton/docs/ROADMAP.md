# Roadmap

Strictly sequential milestones (docs/PLAN.md, "Roadmap"). One milestone at a time; nothing from a later milestone is built early. A milestone ends when its done-when criteria and the quality bar are met, never because time ran out.

Written by the second task in docs/NEXT.md, once docs/DESIGN.md is accepted.

## Checkpoints

Every milestone ends with a checkpoint issue. Development waits for the owner's `/go`, `/iterate <what>` or `/pivot <how>` before the next milestone starts; scheduled bug fixes keep going meanwhile.
